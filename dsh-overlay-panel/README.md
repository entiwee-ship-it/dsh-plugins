# dsh-overlay-panel

DSH Web 的自有界面插件：悬浮工具面板「工具坞」——多视图（token 统计 / 插件列表）。
设计上下文见同目录 `PRODUCT.md`（impeccable 流程产出）。

## 视图切换

头部标题右侧的图标按钮在两个视图间切换，当前视图持久化到
`localStorage["dsh-overlay-panel.view"]`：

- **token 统计**（默认）：见下节；
- **插件列表**：组合插件清单（`remote.pluginInventory`，entryId / 启用态 /
  Fiber 阶段徽章，失败置顶、禁用沉底）+ 本进程动态插件清单
  （`remote.dynamicCordisRunner`，版本数 / 运行状态），顶栏刷新按钮手动重拉。

## 面板能力（token 统计 v1.0）

- **时间维度**：今日 / 本周 / 本月 / 累计，默认今日；tab 行右侧展示当前维度覆盖的
  数据日期范围（累计取全部会话中最早有记录的一天）。
- **精确按日统计**：宿主半边（`index.js`）注册 `dailyUsage` 会话投影，沿官方
  `tokenUsage` / `sessionStats` 同口径折叠会话日志事件，产出每个会话按自然日的
  token 四桶（输入/输出/缓存读/缓存写）与轮/步数；投影经 `session/projection`
  帧推送客户端。冷会话（归档/子代理）由启动时的冷读预热补齐缓存行。
  投影缺席时退回本地按日基线差值（`localStorage[".usageDaily"]`，保留 14 天）。
- **全站摘要**：总 token、主会话数、归并子代理数、缓存命中率徽章（一位小数）、
  数据状态（日志精确 / 同步中）与最近更新时间（追踪统计数字实际变化，非行
  `updatedAt`）；输入/输出/缓存读占比条按真实比例渲染（缓存写为 Anthropic 概念，
  DeepSeek 系不回报，不展示）。
- **会话排行**：按工作区分组的展开/收缩列表（折叠状态持久化），归档会话统一进
  「已归档」组（默认收缩、永远垫底），未收纳会话进「未分组」组；组间按总量降序。
  子代理会话不单独上榜，用量沿 `parentId` 链并入发起它的主会话行，行侧 `+N`
  徽标展示归并数量与明细（只统计当前维度确有消耗的子代理，与顶部数量严格一致）。
  行点击直接打开该会话；命中率显示会话自身口径（与 GUI 会话统计行一致），
  含子代理合计值在悬浮提示中。
- **布局**：顶部摘要固定、「会话排行」为唯一滚动区（6px 细滚动条，悬停加深，
  暗色适配）、底部轮/步汇总固定；内容超高时仅排行区滚动。

## 形态与动效

- **极简圆形 FAB**：白底 + indigo 签名色（oklch 260°）panel-right 图标，可任意拖动；
- **浮动面板**：380px 卡片，标题栏六点抓取纹提示可拖动，Esc 或 ✕ 收起；
  拖动钳制用面板**真实高度**（ResizeObserver 同步）；
- **锚点永远属于 FAB**：面板被拖动时锚点跟随到面板靠屏幕边缘一侧的上角
  （右半屏取右上角、左半屏取左上角），关闭面板时收缩动画终点与 FAB 落点
  严格一致，不跳变；贴边打开再收起，FAB 回到原处；
- **展开方向：默认从右到左、从上到下，放不下才换向**；打开后按真实高度再对齐一次；
- **缩放展开动画**：220ms ease-out 展开 / 160ms 收起，transform-origin 指向
  FAB 将出现的位置；`prefers-reduced-motion` 退化为 120ms 纯淡入淡出；
- **位置、开关与分组折叠状态持久化**：`localStorage`（`.open` / `.pos` / `.collapsed`）。

## 结构

| 文件 | 作用 |
| --- | --- |
| `package.json` | `dsh.client` 声明（`platform: web`）+ `exports["./client"]`；**必须保留 `./package.json` 导出**，否则宿主扫描会缓存否定判定（内存态，进程内不失效） |
| `index.js` | Node 半边：注册 `dailyUsage` 会话投影，并为全部已存储会话做冷读预热 |
| `client.js` | 浏览器半边：手写 lazy-CJS bundle（与 tsdown 产物同构），`apply(ctx)` 里用 React portal 挂浮动面板 |

## 挂载

`~/.dsh/profiles/web/cordis.patch.yml`：


## 热插拔边界（实测 2026-08-14）

| 操作 | 表现 |
| --- | --- |
| 改 `client.js` 保存 | **完全热**：client-hmr stat-poll 发现 rev 变化，SSE 推送，已打开页面免刷新重载（React 状态丢失，面板开关态经 localStorage 保留） |
| 改 `index.js` 保存 | **需重启 DSH**：宿主半边无 HMR；投影注册与冷读预热在启动时执行 |
| patch 新增插件行 | 宿主热生效；**已打开页面需刷新一次**拿新启动图 |
| patch 禁用/删除行 | 宿主立即从启动图移除；**已打开页面需刷新**面板才消失 |

## 已知边界

- 供应商只在每个步骤完成时回报用量，数字随步骤边界刷新（步骤内的逐 token
  实时增长在数据上不可达）；面板在有运行会话时以 5s 节奏反映最新值。
- 本地基线回退路径仅保留 14 天，「本月」在回退模式下最多覆盖最近 14 天；
  投影在线时无此限制。
